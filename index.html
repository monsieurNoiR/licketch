Licketch

基本的な使い方

  1. 録音する 「録音」タブで REC ボタンをタップして演奏を開始。無音が約 1.5 秒続くと自動でマークが打たれます。演奏が終わったら再度タップ（STOP）。
  2. 波形を確認する 録音停止後、自動的に「波形」タブへ移動。セグメントごとに ▶ ボタンでプレビュー再生できます。波形の左右のハンドルをドラッグしてトリム範囲を調整できます。
  3. 保存する 保存 ボタンで WAV ファイルとして保存します。次へ ▶ で次のセグメントへ進めます。全セグメントを確認すると「一覧」タブへ移動します。
  4. 一覧で管理する 「一覧」タブで保存済みのフレーズを確認・再生・ダウンロードできます。長押しで個別削除、右上の「選択」ボタンで複数選択して一括削除もできます。

ブラウザを閉じても録音データはバックグラウンドで保持されます。再起動時に「未処理の録音があります」と表示されたら「OK」で波形確認を再開できます。

ホーム画面へのインストール

インストールするとマイクの許可が保持され、アドレスバーのないアプリとして起動できます。

iOS / iPadOS（Safari）

  1. Safari でこのページを開く
  2. 画面下部の 共有ボタン（□に↑のアイコン）をタップ
  3. 「ホーム画面に追加」 を選択
  4. 名前を確認して 「追加」 をタップ
  5. ホーム画面のアイコンから起動するとスタンドアロンモードで動作します

Chrome on iOS ではホーム画面への追加ができません。必ず Safari を使用してください。

Android（Chrome）

  1. Chrome でこのページを開く
  2. 右上の メニュー（⋮） をタップ
  3. 「アプリをインストール」 または 「ホーム画面に追加」 を選択
  4. 確認ダイアログで 「インストール」 をタップ

オーディオインターフェースの接続

  1. USB-C ケーブルでオーディオインターフェースを iPad に接続する
  2. iOS が自動認識します（ドライバーのインストールは不要）
  3. REC ボタンをタップして録音を開始すると、接続した機器の入力が使われます

Lightning ポートの iPad は USB-C→Lightning 変換アダプター経由で接続できますが、動作は保証されません。Bluetooth オーディオデバイスは遅延が大きいため非推奨です。

接続が認識されない場合は、GarageBand などで入力が確認できるか先に試してください。

よくある問題

マイクの許可ダイアログが毎回表示される

Safari の仕様で、ブラウザとして開いているとページを再読み込みするたびに許可が求められます。ホーム画面に追加して PWA として起動すると、セッション中は再確認されなくなります。

「マイクへのアクセスが許可されていません」と表示される

設定アプリ → Safari → マイク を「確認」または「許可」に設定してください。PWA の場合は 設定 → プライバシーとセキュリティ → マイク から Licketch を許可してください。

波形が表示されない

録音データがない状態では「波形」タブは無効（グレー表示）になります。録音を行うと自動的に波形確認画面へ移動します。ページをリロードした場合は再度録音してください。

再生ボタンを押しても音が出ない

ブラウザの自動再生ポリシーにより、ページ読み込み直後は音声が再生できない場合があります。▶ ボタンを直接タップしてください。それでも再生されない場合はページをリロードして録音し直してください。

録音中にアプリを切り替えると録音が止まる

iOS の仕様です。録音中は他のアプリへの切り替えを避けてください。誤って切り替えた場合、停止前のデータは波形確認画面で確認できます。

保存したファイルはどこに？

iPad / iPhone：一覧画面の ↓ ボタンでダウンロードしたファイルは「ファイル」アプリ → 「ダウンロード」フォルダに保存されます。

Android：「ファイル」アプリまたは「ダウンロード」フォルダに保存されます。

アプリ内のデータ（一覧画面のフレーズ）はブラウザのストレージ（IndexedDB）に保存されており、ファイルアプリからは見えません。大事なフレーズは必ず ↓ ボタンでダウンロードしてバックアップしてください。

保存したフレーズが消えた

フレーズのデータはブラウザの IndexedDB に保存されています。「Safari の履歴とウェブサイトデータを消去」や「サイトのデータを消去」を行うと削除されます。重要なフレーズは必ずダウンロード（↓ ボタン）してバックアップしてください。

フレーズが正しく分割されない・無音区間が残る

無音検知の閾値は -50 dB、判定時間は 1.5 秒に設定されています。環境ノイズが大きい場合や、短い休符の多い演奏では誤検知が起こることがあります。波形確認画面でトリムハンドルを手動で調整して対応してください。
